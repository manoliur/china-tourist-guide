# Справочник туриста в Китае

Офлайн PWA-справочник для русскоязычного туриста в Китае: экстренная помощь,
что нельзя по закону, консульская защита, Alipay, транспорт, безвиз,
разговорник — со ссылками на официальные источники у каждой записи.

## Зачем именно так

- В Китае заблокированы Telegram, Google, YouTube, Instagram, WhatsApp —
  обычный сайт может не открыться. Значит нужен **офлайн**: весь контент
  зашивается в приложение при первой загрузке и работает без сети.
- **PWA, а не нативное приложение**: устанавливается прямо из браузера ещё в
  России, весит меньше 1 МБ (нативные приложения — обычно 50–200 МБ), не
  зависит от App Store/Google Play, которые в Китае тоже режутся.
- Никаких внешних CDN и Google Fonts — они тоже недоступны из Китая. Шрифт
  self-hosted, все ассеты локальные.

## Для кого

Для туриста из России, впервые едущего в Китай без знания языка — как
карманный справочник на случай, если что-то пошло не так (экстренная
ситуация, потеря документов, непонятная надпись в меню, вопрос про Alipay),
а не для оформления визы или планирования маршрута.

## ⚠️ Дисклеймер

Это справочник, составленный по официальным источникам, а **не медицинская
или юридическая консультация**. В опасной ситуации звоните 120 (скорая) /
110 (полиция) / 12308 (МИД КНР, справочно) — номера консульства РФ см. в
приложении на вкладке SOS.

Часть записей помечена «требует проверки» — это честная маркировка того,
что факт не подтверждён прямой загрузкой официального первоисточника в
процессе подготовки (например, обрыв соединения при попытке открыть
страницу ведомства). Не полагайтесь на такие записи как на 100% точные без
самостоятельной перепроверки перед поездкой.

## Как установить на телефон

1. Откройте ссылку на сайт в браузере телефона (**в России**, до выезда —
   тогда контент скачается и останется на устройстве)
2. iOS (Safari): кнопка «Поделиться» → «На экран «Домой»»
   Android (Chrome): меню (⋮) → «Установить приложение» / «Добавить на
   главный экран»
3. Откройте приложение хотя бы один раз с интернетом — это загрузит и
   закэширует все 16 разделов. После этого интернет для работы справочника
   не нужен.

**Итого: 84 записи в 16 разделах** + разговорник (18 фраз с пиньинем).

Плюс 5 функциональных экранов: Справочник · Поиск · SOS (звонок в один тап) ·
Калькулятор ¥↔₽ (офлайн, курс задаётся вручную) · Разговорник.

У каждой записи справочника: уровень доказательности (A/B/C), статус
(переведено / адаптировано / написано заново), ссылки на источники, дата
последней проверки.

## Источники

Часть контента — перевод и адаптация из книги
**[How To Live Better](https://github.com/eternity4719/HowToLiveBetter)**
(лицензия **Unlicense** — общественное достояние). Остальное написано заново
по официальным источникам: законы и постановления КНР, официальные сайты
госорганов (НБК, МИД КНР, Госуправление миграции, консульства РФ) и
компаний (Alipay). Правило источников для нового контента, которому
следовал проект: только первоисточники, вторичные медиа (блоги, форумы)
никогда не используются как подтверждение факта — см. `CLAUDE.md`.

## Технологии

- [Vite](https://vitejs.dev/) + [vite-plugin-pwa](https://vite-pwa-org.netlify.app/) (service worker, манифест)
- Шрифт [Manrope](https://github.com/sharanda/manrope) (вариативный, self-hosted, SIL OFL-1.1) — без Google Fonts
- Собственный набор SVG-иконок (`src/icons.js`) — без эмодзи, без иконочных библиотек
- Ванильный JS, без фреймворка

## Локальная сборка

```bash
npm install
npm run dev       # разработка, http://localhost:5173
npm run build     # сборка в dist/ (< 1 МБ)
npm run preview   # локальный просмотр собранной версии
```

При изменении содержимого справочника (`src/content/*.json`) не забудьте
синхронизировать копию для рантайм-загрузки:

```bash
cp src/content/*.json public/content/
```

(Vite отдаёт `public/` как есть — оттуда приложение читает JSON через
`fetch()` в браузере; `src/content/` остаётся каноническим источником для
редактирования.)

## Структура проекта

```
src/
  content/         канонические JSON-файлы (16 разделов + разговорник)
  main.js          вся логика приложения (рендер, поиск, калькулятор, PWA)
  icons.js         инлайн-спрайт SVG-иконок
  style.css        дизайн-система (токены, типографика, анимации)
public/
  content/         копия src/content/ для fetch() в рантайме
  fonts/           self-hosted Manrope (woff2) + лицензия OFL
  icon-*.png       PWA-иконки
vite.config.js     сборка + PWA-плагин (precache всего контента)
```

## Честно о том, чего нет

- Точный список DiDi-такси для иностранцев не подтверждён официальным
  источником — запись честно помечена как требующая проверки, без вымышленных
  деталей.
- Курс валют в калькуляторе не тянется из внешнего API (специально — лишняя
  сетевая зависимость для приложения, рассчитанного на страну с
  заблокированным интернетом, это лишняя точка отказа); курс вводится вручную
  и сохраняется на устройстве.
